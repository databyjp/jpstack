Research the following topic:

$@

Use any timeframe specified in the request. Otherwise choose an evidence window appropriate to the question and state it explicitly.

Investigate:

- Current facts, capabilities, releases, and official positioning
- Independent reception, adoption, maintenance, and reputation
- Meaningful alternatives and competing explanations
- Evidence that contradicts the apparent consensus
- Whether important claims or reference documents are outdated

Use primary sources for factual product claims and independent sources for reception and adoption. Verify consequential claims against exact source passages. Remove duplicate findings.

Return a concise synthesis containing:

1. The main conclusions
2. The strongest supporting evidence
3. Important qualifications or contradictory evidence
4. Recommended next steps when the question calls for a decision
5. A short list of the most useful sources
